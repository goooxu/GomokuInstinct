# 技术报告：从规则到棋感

这是一份关于 **gomoku-instinct** 的技术报告 —— 一个从零开始、只靠游戏规则自我对弈
训练出来的连珠（五子棋）AI，它在对战时**不使用任何搜索**，落子完全由一次网络前向决定。

报告写给**会用 PyTorch、但没有强化学习背景**的读者。不假设你听说过 AlphaZero、
MCTS、PUCT 或自博弈；这些概念都在正文里从零讲起。

## 术语表

按第一次出现的章节排序。

| 术语 | 含义 |
|---|---|
| **连珠 / Renju** | 加了禁手规则的五子棋。黑方（先手）被限制，用来抵消先手优势。第 1 章 |
| **禁手** | 黑方不许形成的棋型：长连、四四、三三。本项目采用严格 RIF 语义 —— 禁手点仍是**合法落子**，落上去立即判负。第 1 章 |
| **活三 / 冲四 / 活四** | 威胁棋型。活三 = 再走一子能成活四；活四 = 两端都能成五，对手挡不住。第 2 章 |
| **RIF** | 国际连珠联盟（Renju International Federation）的规则标准。第 2 章 |
| **平面 / plane** | 喂给网络的一层 `15×15` 布尔或实数图。多个平面沿通道维堆叠成输入张量。第 3 章 |
| **策略头 / policy head** | 网络输出的一张"每个点该下的概率"图。第 3 章 |
| **价值头 / value head** | 网络输出的"当前行棋方最终会赢还是会输"的估计。第 3 章 |
| **logits** | softmax 之前的原始分数。屏蔽非法点就是把它们的 logit 设成 `-inf`。第 3 章 |
| **辅助监督头 / auxiliary head** | 除策略和价值之外，额外让网络预测的东西（棋型、禁手点等）。标签由规则免费导出。第 4 章 |
| **depthwise 卷积** | 每个输入通道各自卷各自的，不跨通道混合。参数量是普通卷积的 `1/C`。第 4 章 |
| **dilation（空洞）** | 卷积核的采样点之间留空隙。dilation=3 表示每隔 3 格取一个点。第 4 章 |
| **BF16** | bfloat16，16 位浮点。指数位和 FP32 一样宽，但尾数只有 7 位存储位。第 5 章 |
| **ULP** | unit in the last place，一个浮点数与它相邻的下一个可表示数之间的距离。第 5 章 |
| **Kahan 补偿求和** | 把每次加法被舍掉的低位存起来，下次补回去。第 5 章 |
| **自博弈 / self-play** | 让程序自己跟自己下棋，用产生的对局作训练数据。第 6 章 |
| **MCTS** | 蒙特卡洛树搜索。反复"试着往下走几步看看结果"，用统计到的访问次数决定这一手下哪。第 6 章 |
| **PUCT** | MCTS 里决定"下潜时选哪个子节点"的公式，在"已知的好"和"没试过的"之间权衡。第 6 章 |
| **模拟 / simulation / sim** | MCTS 的一次完整下潜-评估-回传。sims=400 表示每手棋做 400 次。第 6 章 |
| **蒸馏 / distillation** | 让网络去拟合另一个更强的东西的输出。这里是让策略头拟合 MCTS 的访问分布。第 6 章 |
| **Dirichlet 噪声** | 加在根节点先验上的随机扰动，逼自博弈去试没试过的着法。第 6 章 |
| **回放池 / replay buffer** | 存放最近若干局面的滑动窗口，训练时从中随机采样。第 7 章 |
| **样本复用比** | 每条样本平均被训练用到几次。太高说明自博弈跟不上，网络在反复啃旧数据。第 7 章 |
| **Elo** | 棋类等级分。差 400 分约等于胜率 10:1。第 9 章 |
| **argmax** | 取最大值所在的位置。零搜索部署时，落子 = 策略头 logits 的 argmax。第 10 章 |

## 一句话免责

第 12 章会说清楚：这个模型**不强**。它稳赢随机落子和贪心规则基线，但只相当于
个位数次模拟的 MCTS。报告的价值在于把"怎么做"和"哪里没做成、为什么"都写下来，
而不是宣称做出了一个强引擎。
